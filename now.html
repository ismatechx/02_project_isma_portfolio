What I'm doing now.

Last updated: June 2026

A snapshot of where my focus is right now — loosely inspired by Derek Sivers' /now page idea. Updated when things change.

Currently

Senior BI Analyst at Zuci Systems (USA), building Power BI dashboards on top of patient insurance data — member details, service codes, diagnosis codes, with automated validation between source and target layers.

Outside the day job: bringing GenAI tooling into the BI workflow. I want every dashboard to come with a small LLM-based explainer agent that can reconcile cross-system numbers in plain English.

Learning

  • Claude API patterns — prompt caching, tool use, structured outputs
  • RAG over enterprise BI metadata (Tableau Lineage + GraphQL extracts)
  • Evaluation: how to actually measure "is the LLM right" beyond vibes
  • Microsoft Fabric — lakehouse + semantic models

Building

This portfolio is the experiment in progress — an AI Analytics positioning, a 3D skills sphere, a desktop-OS alternate view (ISMA OS), and an in-page chat (Ask Ismail AI) that runs on the Claude API.

Side project sketches: a small RAG playground that ingests a job description and explains how my experience maps to it.
